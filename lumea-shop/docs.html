Documentation

How the LUMÉA webshop is built and which requirements are implemented.

1. Theme

Interactive webshop: luxury skincare brand “LUMÉA”.

2. Pages

  • index.html — homepage
  • shop.html — product listing (AJAX + JSON + pagination + filter/sort)
  • product.html — product details via URL param (id)
  • cart.html — LocalStorage cart
  • checkout.html — form + regex validation + errors
  • about.html — author page (required)
  • docs.html — documentation (required)

3. Code reuse

Header and footer are reused across all pages using fetch() from partials/header.html and partials/footer.html.

4. Native JavaScript

  • Dynamic rendering from data/products.json using fetch()
  • Event delegation for buttons (Add to cart, cart actions)
  • Pagination (client-side)
  • Filtering (category, skin type, max price + sale/bestseller)
  • Sorting (price, rating, name)

5. Regular expressions (Regex)

  • Full name validation
  • Email validation
  • Phone validation (SR formats)
  • ZIP code validation (5 digits)

6. Error handling

  • Try/catch around all fetch requests
  • User-friendly messages when JSON fails to load
  • Product page 404 (invalid/missing id)
  • Form errors displayed under each field

7. LocalStorage

  • Cart stored in localStorage key: lumea_cart
  • Cart badge in header updates after actions
  • Optional: last order stored in lumea_last_order

8. SEO basics

  • Each page has a unique title and meta description
  • Semantic structure: header/nav/main/footer
  • Alt attributes for product images
